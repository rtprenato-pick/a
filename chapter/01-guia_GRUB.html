🛠️ Guia de Resgate do GRUB

Como carregar o Linux manualmente no terminal grub>
1

Encontrar a partição do Linux

Liste todas as partições reconhecidas e verifique o conteúdo de cada uma até achar a que contém a pasta /boot.

grub> ls
grub> ls (hd0,gpt1)/
grub> ls (hd0,gpt2)/
O que faz: O ls usa os drivers internos do GRUB para ler as pastas da partição. Você achou a partição certa quando ver pastas como boot/, etc/, usr/ ou arquivos do sistema.
2

Definir a partição de trabalho

Aponte o GRUB para a partição que você localizou no Passo 1 (exemplo usando hd0,gpt2):

grub> set root=(hd0,gpt2)
O que faz: Não lê nada no disco ainda! Apenas define a partição de referência. A partir de agora, digitar a barra / significa acessar a raiz de (hd0,gpt2).
Teste de Confirmação: Digite ls /. O resultado DEVE ser idêntico ao comando ls (hd0,gpt2)/ do passo anterior.
3

Carregar o Kernel do Linux

Carregue o motor principal do sistema e diga a ele qual partição deve ser montada como sistema principal:

grub> linux /boot/vmlinuz-xxx root=/dev/sda2
O que faz:
  • linux /boot/vmlinuz-...: Copia o arquivo do Kernel do disco para a memória RAM.
  • root=/dev/sda2: Passa como instrução para o Kernel onde ele deve buscar o restante do sistema ao inicializar (substitua pelo nome da sua partição no Linux, ex: sda2 ou nvme0n1p2).
💡 Dica da tecla TAB: Digite linux /boot/vmlinuz- e aperte TAB. O GRUB vai preencher automaticamente o nome da versão do seu Kernel!
4

Carregar os drivers iniciais (initramfs)

Carregue a imagem da memória RAM inicial que contém os drivers básicos do sistema:

grub> initrd /boot/initrd.img-xxx
O que faz: Coloca na memória RAM os módulos e drivers necessários para que o Kernel consiga se comunicar com os discos e montar o sistema de arquivos final.
💡 Dica da tecla TAB: Digite initrd /boot/init e aperte TAB para o GRUB autocompletar o nome do arquivo da mesma versão do Kernel.
5

Dar a partida e passar o controle

Com o Kernel e o Initrd carregados na RAM, ordene a inicialização:

grub> boot
O que faz: Dá a partida no processador para executar o Kernel na memória RAM. O GRUB se encerra e a tela do Linux começará a carregar.
6

Após entrar no Linux (Reparar o GRUB)

Assim que o sistema iniciar, abra o terminal e repare a instalação para não ter que fazer tudo manualmente de novo:

sudo grub-install /dev/sda
sudo update-grub
